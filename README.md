# (gwz) Agent Skills

Skills I use every day — from development to sorting out my music collection.
They live here as they are, no build step, no rituals.

## Skills

| Skill | What it does |
| --- | --- |
| [`zsh-completion`](skills/zsh-completion/) | Generates artifacts for the zsh completion system: `_command` files wired in through `compinit`. In plain terms, it's those very options and flags that drop down when you hit Tab. |

## Installation

There's no single instruction for all of them. Each skill has its own
requirements and its own way of being distributed: one is installed by cloning
into `fpath`, another by copying the directory. Install per the README inside
the skill: `skills/<name>/README.md`.
